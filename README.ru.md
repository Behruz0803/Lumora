# PriceRadar

**Знайте рынок. Покупайте умнее. Экономьте больше.**

**Языки:** [English](./README.md) · [O‘zbekcha](./README.uz.md) · **Русский**

PriceRadar — B2B-платформа анализа рынка и сравнения цен для продуктовых магазинов,
ресторанов, розничных продавцов, оптовиков и малого бизнеса в Узбекистане.

Она **не** просто показывает минимальную цену за единицу. Для каждого заказа она считает
**полную стоимость закупки** — цена за единицу × количество **плюс доставка** — и никогда
не рекомендует предложение, которое не может закрыть запрошенное количество.

> **Все цены, поставщики, рейтинги и тренды в этом проекте — вымышленные демо-данные.**
> Интерфейс, ответы API и ассистент явно это указывают. Здесь нет реального
> исследования рынка.

## 1. Что входит в проект

| Область | Реализовано |
| --- | --- |
| Аутентификация | Регистрация, вход, JWT, обновление профиля, смена пароля, демо-аккаунт |
| Панель управления | KPI, тренд цен за 30 дней, последние изменения цен, топ категорий, последние предложения, быстрый поиск |
| Сравнение цен | Поиск товара, ввод количества, рейтинг по полной стоимости, правила допуска, экономия, сортировка (стоимость / качество / доставка), связь с поставщиком и сводка заказа |
| Товары | Поиск, фильтр по категории, фильтр наличия, сортировка, постраничный вывод, карточка товара, график истории цен за 30/90/180 дней, список предложений |
| Поставщики | Справочник, фильтр по городу, только проверенные, сортировка, профиль с контактами и предложениями |
| Аналитика рынка | График тренда, средние цены по категориям, состояние предложения, индикаторы спроса, выбор истории товара, периоды 30/90/180 дней |
| AI-ассистент | Прозрачный движок на правилах (без внешней модели): сравнивает предложения, объясняет победителя, считает суммы, суммирует тренды |
| Сохранённые предложения | Сохранение / удаление, отслеживание изменений цены и статуса, сравнение выбранных предложений бок о бок |
| Настройки | Профиль, данные бизнеса, язык интерфейса, уведомления, смена пароля |
| **Языки** | **Узбекский, русский и английский** во всём интерфейсе, включая демо-названия товаров и пояснения, которые формирует сервер |
| Бэкенд | FastAPI + SQLAlchemy 2 + Pydantic v2, готов к PostgreSQL, dev-вариант на SQLite, демо-данные, OpenAPI |
| Реальные данные | Импорт прайс-листов в CSV (dry-run + ошибки по строкам), эндпоинты товаров/поставщиков, происхождение данных (демо / смешанные / реальные) и соответствующий баннер |
| Качество | 185 бэкенд-тестов, 126 фронтенд-тестов, живой smoke-набор из 126 проверок + 60 adversarial-проб, QA-отчёт |

Killer Flow (реализован полностью): Дилшоду нужно **100 кг картофеля** → он ищет → вводит
100 кг → видит поставщика A 450 000, B 400 000, C 420 000 UZS → рекомендуется поставщик B
как минимальная **полная** стоимость → пояснение → связь с поставщиком → сводка заказа
с экономией 50 000 UZS относительно поставщика A.

## 5. Полная стоимость и движок рекомендаций

**Формула:** `Полная стоимость = (цена за единицу × количество) + доставка`

Пример — картофель, 100 кг:

| Поставщик | Цена за ед. | Стоимость товара | Доставка | **Итого** | Статус |
| --- | --- | --- | --- | --- | --- |
| Fergana Fresh Produce (B) | 3 500 | 350 000 | 50 000 | **400 000** | ✅ рекомендация |
| Bukhara Farm Direct (C) | 4 200 | 420 000 | 0 | 420 000 | допущен |
| Tashkent Agro Trade (A) | 4 000 | 400 000 | 50 000 | 450 000 | допущен |
| Namangan Food Supply | 3 300 | 330 000 | 30 000 | 360 000 | ❌ нет в наличии — не ранжируется |

Правила:

1. Расчёты в целых UZS, `Decimal` с округлением половины вверх.
2. Предложения без наличия (`out_of_stock`), с недостаточным запасом или ниже минимального
   заказа **никогда** не рекомендуются.
3. Рейтинг по полной стоимости; при равенстве — по рейтингу, затем по id (стабильно).
4. «Лучшее в целом» учитывает также качество/скорость и явно показывает разницу.
5. Каждый ответ содержит `data_source: "demo"` и предупреждение о вымышленных данных.

## 6.1. Реальные цены поставщиков (из демо в реальные данные)

Проект работает на вымышленных демо-данных, но перейти на **реальные цены
поставщиков** можно без изменения кода:

1. **Скачайте шаблон** — `/api/import/template` (ссылка есть и на странице
   *Импорт цен*).
2. **Заполните его из прайс-листов** — обязательные колонки `product`,
   `supplier`, `unit_price`; необязательные `delivery_cost`,
   `minimum_order_quantity`, `available_quantity`, `status`, `category`, `unit`,
   `phone`, `location`. Заголовки принимаются на английском, узбекском и русском
   (`mahsulot`, `taminotchi`, `narx`, `товар`, `поставщик`, `цена`, ...).
3. **Проверьте файл** — страница сначала валидирует его и показывает таблицу
   ошибок по строкам, ничего не записывая (`POST /api/import/prices?dry_run=true`).
4. **Импортируйте** — корректные строки становятся реальными предложениями
   (`is_demo = false`), отсутствующие товары/поставщики создаются, предложение
   той же пары товар+поставщик обновляется, и каждая строка добавляет точку в
   историю цен — графики и аналитика сразу считаются по реальным данным.

Происхождение данных не угадывается: `GET /api/dataset/status` сообщает, сколько
товаров, поставщиков и строк цен реальны, а каждый ответ сравнения и аналитики
содержит `data_source` = `demo` | `mixed` | `real` и соответствующий `disclaimer`.
В интерфейсе демо-баннер становится зелёным («Импортированный прайс-лист») только
когда **все** цены пришли из импорта.

Демо-строки защищены: импорт может их обновить (реальная цена заменяет демо), но
удалить строки с `is_demo` через `/products/{id}` или `/suppliers/{id}` нельзя.

## 8. Языки (English · O‘zbekcha · Русский)

* **Где переключать:** `EN/UZ/RU` в верхней панели, переключатель в боковом меню и на
  странице входа.
* **Что переведено:** навигация, панели, таблицы, графики, формы, сообщения валидации,
  тосты, пустые и ошибочные состояния, экран ассистента, копируемый заказ на закупку и
  подписи демо-данных (названия товаров, категории, единицы, города).
* **Текст с сервера тоже:** пояснение рекомендации, причины отказа и все ответы ассистента
  приходят на активном языке (`Accept-Language` или `?lang=`).
* **Настройка профиля:** язык, выбранный в **Настройки → Язык и уведомления**, записывается
  в аккаунт через `PATCH /api/auth/me`.
* **Числа, даты и склонения:** в русском — формы one/few/many, в узбекском — одна форма,
  валюта — UZS с группировкой пробелами.

Добавление языка: скопируйте `frontend/src/i18n/locales/uz/ui.ts`, переведите значения,
добавьте код в `LANGUAGES` (`i18n/core.ts`) и в `SUPPORTED_LANGUAGES`
(`backend/app/core/i18n.py`). `npm run i18n:keys` обновляет ключи, а
`src/test/i18n.test.tsx` сразу сообщит о пропущенном переводе.

## 11. Известные ограничения

* **Все данные вымышленные.** Нет парсинга, потоков поставщиков или живой интеграции рынка.
* «AI»-ассистент — детерминированный движок на правилах. Языковая модель не подключена,
  и он сообщает об этом в каждом ответе. Понимает вопросы на английском, узбекском и
  русском (по ключевым словам).
* Настройки уведомлений сохраняются, но письма и push не отправляются.
* «Связаться с поставщиком» — демонстрационный поток: телефон, ссылка `tel:` и копируемый
  заказ. Он не отправляет сообщений и не размещает заказ.
* Редактирование/удаление предложений, роль администратора, загрузка файлов, refresh-токены
  и rate limiting выходят за рамки MVP.
* Схема создаётся через `create_all` (не Alembic).
* Визуальная регрессия в настоящем браузере и тесты на устройствах в QA-песочнице были
  недоступны; поведение проверено DOM-тестами, адаптивность — статическим аудитом.
* Docker compose не запускался (см. выше).

## 12. Безопасность

* Пароли хранятся в **bcrypt** (cost 12) после предварительного SHA-256 — пароли длиннее
  72 байт никогда не обрезаются молча.
* JWT подписывается `SECRET_KEY` и имеет срок действия (по умолчанию 7 дней).
* Защищённые эндпоинты (`/auth/me`, `/saved-offers`, `POST /offers`) требуют токен;
  сохранённые предложения изолированы по пользователю.
* CORS открыт только для настроенных источников (и опционального домена preview).
* Секреты — в `.env`; `.env.example` служит образцом, `.env` не попадает в git.
* Ответы с ошибками никогда не возвращают пароль или значение токена.
